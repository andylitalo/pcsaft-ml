# pcsaft-predict Package Manifest

## Version: 1.0.0

## Package Contents

### Core Modules
- __init__.py          - Public API exports
- _registry.py         - Model registry and high-level API
- _features.py         - Feature computation (Morgan FP + RDKit descriptors)
- _rf.py               - Random Forest model wrapper
- _ad.py               - Applicability domain (Tanimoto NN)
- _thermo.py           - Thermodynamic properties (optional, requires teqp)
- _weights.py          - Weight cache management

### Documentation
- README.md            - User-facing documentation
- pyproject.toml       - Package metadata and dependencies

### Type Checking
- py.typed             - PEP 561 marker for type hints

### Data
- data/.gitkeep        - Placeholder for data directory

## Required Model Files (not included in package)

The following files must be present in the cache directory:

### RF Models (required)
- rf_m.joblib          - Random Forest for m parameter
- rf_sigma.joblib      - Random Forest for sigma parameter
- rf_epsilon_k.joblib  - Random Forest for epsilon_k parameter

### Feature Configuration (required)
- feature_names.joblib - List of feature names from training
- rdkit_scaler.joblib  - StandardScaler for RDKit descriptors

### Applicability Domain (optional)
- tanimoto_ad.joblib   - Precomputed training set fingerprints for AD


## Cache Directory Resolution

The package looks for model weights in the following order:

1. `$PCSAFT_PREDICT_CACHE_DIR` (if set)
2. `../model/saved/` (if package is in repo)
3. `~/.cache/pcsaft_predict/` (default fallback)
